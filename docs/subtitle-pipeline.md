# 이중 자막을 만드는 순서

영상을 열면 `SubtitleJob`(`app/lib/src/pipeline/subtitle_job.dart`)이 아래 순서로 원문 자막과 한국어 자막을 마련하고 싱크를 맞춘다.
원칙은 **이미 있는 것을 먼저 쓰고**(바로 보여 주기), **없는 것만 만들고**(음성 인식·AI 번역), **시간이 의심스러운 것은 음성과 대조해 옮긴다**는 것이다.

## 1. 저장된 결과

같은 영상을 전에 열었으면 저장된 자막·번역·싱크를 그대로 쓴다. 다음 경우는 버리고 처음부터 다시 만든다.

- 이전 버전 형식, 실시간 보정이 음성 인식 자막을 잘못 옮긴 결과
- YouTube 자막인데 지금 알아낸 음성 언어와 언어가 다른 결과

음성 인식이 중간에 멈췄던 결과는 남은 구간만 이어서 인식한다.

## 2. 원문 자막 찾기

| 영상 | 순서 |
|---|---|
| YouTube | ① 음성 언어의 YouTube 자막 (사람이 만든 자막 → 음성 받아쓰기 자동 자막). 음성 언어를 YouTube가 알려 주지 않으면(자막이 여러 언어로 있는 TED 등) 첫 조각을 음성 인식해 언어를 알아낸 뒤 그 언어 자막으로 바꾼다 ② 없으면 음성 인식 |
| 로컬 파일 | ① 내장 자막 (데스크톱만, Android는 내장 자막을 읽지 못한다) ② 인터넷 자막 (OpenSubtitles, 키가 있을 때. 파일 해시 → 이름 검색, 영상 길이가 맞아야 함) ③ 없으면 음성 인식 |

내장·인터넷 자막은 실제 음성과 같은 내용인지 먼저 확인하고(일부 구간을 음성 인식해 비교), 다르면 버리고 음성 인식한다.

## 3. 한국어 자막 찾기

| 영상 | 한국어 자막 | 붙이는 때 |
|---|---|---|
| YouTube | 사람이 만든 한국어 자막 → YouTube 자동 번역 | 원문을 먼저 보여 주고 뒤에서 받는다. 받으면 그 번역으로 바꾼다 |
| 로컬 파일 | 내장 한국어 자막 → 인터넷 한국어 자막 | 원문과 함께 |

원문 자막이 없어 음성 인식하는 경우에도 한국어 자막이 있으면 쓴다.

- YouTube·내장 한국어 자막은 이 영상과 시간이 같으므로 **인식되는 줄마다 바로** 붙인다
- 인터넷 한국어 자막은 다른 판본일 수 있어 음성 인식이 끝난 뒤 싱크를 맞추고 붙인다

## 4. 싱크 맞추기

음성 인식 자막은 같은 소리에서 시간을 얻었으므로 맞추지 않는다. 그 밖의 자막은:

| 자막 | 방법 |
|---|---|
| YouTube 자막, 내장 자막, Android의 인터넷 자막 | **시작 싱크**: 재생 위치부터 1분(Android 30초)을 음성 인식해 자막과 같은 말이 나오는 시각을 비교하고, 0.7초 넘게 밀려 있으면 전체를 옮긴다 |
| 데스크톱의 인터넷 자막 | **전체 싱크**: 영상 전체 말소리 구간에 원문·한국어 자막을 각각 맞춘다 |
| 로컬 파일의 받은 자막 | **실시간 싱크**: 재생 중 앞으로 90초를 계속 비교해 구간마다 어긋나면 그 지점부터 옮긴다 (광고가 빠진 판본 등) |

그래도 안 맞으면 `[` `]` 키로 0.2초씩 직접 맞춘다. 직접 맞춘 뒤에는 자동으로 옮기지 않는다.

## 5. 번역

한국어 자막이 붙지 않은 줄만 AI로 번역한다. 재생 위치 근처부터 번역한다.

## 사용자가 직접 고르는 것 (상단 메뉴)

| 버튼 | 하는 일 |
|---|---|
| 🎤 자막 자동 생성 | 있는 자막 대신 음성 인식으로 원문을 만들고 번역한다. 이미 음성 인식 자막이면 원래 자막(YouTube·내장·인터넷)으로 되돌릴 수도 있다 |
| ✨ AI 번역 | 원문은 그대로 두고 번역만 AI로 새로 한다 (YouTube·인터넷 한국어 자막 대신) |
